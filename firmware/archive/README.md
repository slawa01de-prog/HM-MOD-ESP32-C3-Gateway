# Firmware-Archiv

Dieser Ordner dokumentiert die Entwicklung vom ersten HB-RF-ETH-Dongle bis zum stabil getesteten
Gateway.

- `v1/` – erster funktionierender ESP32-C3/HB-RF-ETH-Transport
- `v2/` – Umstellung auf vollständige HM-UART-Frames
- `v3` – HM-MOD-.eq3-Updater, in der Projekt-Chronik dokumentiert
- `v3.1` – DualCoPro/WebUI/Diagnose-Ausbau, in der Projekt-Chronik dokumentiert
- `../stable/` – aktuell praktisch getesteter Stand **v3.1.1**

Für produktiven Einsatz bitte ausschließlich die Version unter `firmware/stable/` verwenden.
Die Entwicklungsschritte sind zusätzlich in [docs/10_CHANGELOG.md](../../docs/10_CHANGELOG.md)
beschrieben.
